# CONNECTA v0.14.55 illustration assets

This versioned directory contains 1,077 individually generated and visually reviewed outfit illustrations, used by 1,079 application asset keys. It replaces the active outfit artwork for the 891-look catalogue, editorial, creator and brand pages, six pose sequences, and the premade model studio.

The model studio includes 12 fictional adult models, four existing outfits per model, and two scene categories per outfit (96 images). Of these, 84 depict varied everyday activities and interactions; 12 canonical identity images remain. These are authored illustrations, not a live image-generation or validated virtual-fitting service.

Generated with the built-in image_gen tool using the user's approved fashion-illustration reference and preserved outfit references. Individual prompt, source, generator output, visual review and product-target coordinates are recorded in the project production archive. Standalone product imagery, logos, user uploads, prices, vendor links and identifiers are not replaced.

Earlier release directories remain intact for rollback. The application consumes these files only through its complete v0.14.55 asset manifest.
